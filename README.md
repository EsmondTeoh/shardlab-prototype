# ShardLab – Mobile Group Ordering & Payment Prototype

A mobile-web prototype of a consumer QR ordering and payment journey, with group ordering where one volunteer pays and earns 3% cashback.

- **Live demo:** https://esmondteoh.github.io/shardlab-prototype/
- **Repo:** https://github.com/EsmondTeoh/shardlab-prototype

The app runs inside a 375px-wide Google Chrome mobile frame on every device (the Chrome controls are a static mock-up).

**Run locally:** open `index.html` in a browser. It is one self-contained file with no build step.

See [SUBMISSION.md](SUBMISSION.md) for the walkthrough, what is simulated or incomplete, and the AI-assisted decisions.

All payments, friends and accounts are simulated. No real data is collected or sent.
