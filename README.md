# ShardLab – Mobile Group Ordering & Payment Prototype

A mobile-web prototype of a consumer QR ordering and payment journey, with group ordering where one volunteer pays and earns 5% cashback.

**Live demo:** https://esmondteoh.github.io/shardlab-prototype/ (best on a phone, or browser dev tools at 375x812)

**Run locally:** open `index.html` in a browser. It is one self-contained file with no build step.

See [SUBMISSION.md](SUBMISSION.md) for the walkthrough, what is simulated or incomplete, and the AI-assisted decisions.

All payments, friends and accounts are simulated. No real data is collected or sent.
